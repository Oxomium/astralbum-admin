# Astralbum – page d'administration

Page publiée sur https://admin.astralbum.com (GitHub Pages). Elle ne contient aucun secret : l'adresse du serveur et
la clé publique sont les mêmes que dans l'application. Chaque action est vérifiée par le serveur (compte
d'administration, code à 6 chiffres).

Ne pas modifier ici : la page est fabriquée depuis le dossier `admin/` du dépôt du jeu, puis copiée dans ce dépôt.
